# 成田到新宿與關西到大阪鐵路比較

以到埗站名篩選機場列車。成田到新宿宜核對個別 Narita Express 班次是否停新宿。關西機場出發，JR HARUKA 的大阪站與新大阪站，和南海 Rapi:t 的南海難波站，是三個不同的到站選項。

[CSV 資料](data.csv)每列記錄機場、到站、列車、旅客核對事項、營運方來源及核對日期。此為選定鐵路路線的快照，未包含全日班表、票價、巴士或站外步行時間。請以指定日期的營運方資料安排車程。資料核對日期為 2026-11-19。原創欄位設計及交通整理依[專案 MIT 授權](../LICENSE.md)，外部來源各依原權利人條款。
